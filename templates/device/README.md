## ลักษณะอุปกรณ์

สเปคหลักที่ต้องรู้ก่อนใช้ เช่น ช่วงการวัด ความแม่นยำ ขนาด กระแสที่กิน ลิงก์ datasheet แทนการ copy ตารางทั้งหมด

## Pin / Port

| Pin | หน้าที่   | หมายเหตุ |
| --- | ------ | ------- |
| VCC | ไฟเลี้ยง |         |
| GND | กราวด์  |         |

## การต่อสาย

ต่อกับบอร์ดไหน ขาไหน (ตารางหรือ Mermaid) และอุปกรณ์เสริมที่ต้องใช้ เช่น ตัวต้านทาน pull-up หรือโมดูลแปลงสัญญาณ

## วิธีใช้งาน

library ที่ต้องติดตั้ง (ชื่อ + เวอร์ชันที่ทดสอบ) ขั้นตอนอัปโหลด และผลที่ควรเห็นใน Serial Monitor
