# 0001 — Public repo: team knowledge base that doubles as a customer showcase

The library is written for the GTI team first, but the repo stays **public** so customers and Global Byte buyers can see it. Because anything pushed is world-readable and stays in git history, it must never contain customer names or project details, prices or costs, credentials, `.env` values, or internal network addresses; customer-specific work lives in that customer's private repo and links here, never the reverse.
