# 0002 — Build our own library, but link to existing references instead of rewriting them

DFRobot Wiki, Seeed Wiki, Random Nerd Tutorials and pinout.xyz already publish pinouts, wiring and sample code, so we do not rebuild a general catalog. This library only adds what they lack: Thai-language pages for devices the team has actually tested, with our wiring, working code and the problems we hit; datasheets and general tutorials are linked, not copied (also avoids copyright issues).
